# Changelog

All notable changes to **Read Shell** will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/).

---

## [0.0.1] - Initial Release

### Added
- Initial implementation of Read Shell
- Run shell commands and insert output into the active editor
- Vim‑like workflow inspired by `:r!{cmd}`
- Command history with configurable size
- Custom command snippets
- Configurable stderr handling (`ignore`, `message`, `insert`)
- User‑configurable default shell for Windows and Linux/WSL
- Suggested keybindings for running commands and clearing history
- Extension icon and branding
- README and documentation

## 0.0.2
- Renamed extension from Insert Command Output to Read Shell
- Updated command IDs and activation events
